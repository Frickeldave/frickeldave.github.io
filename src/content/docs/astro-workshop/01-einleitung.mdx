## Worum geht es?

Wer dachte, Produktdokumentationen schreiben sei so spannend wie Farbe beim Trocknen zuzuschauen,
hat Astro und die Node-Linting-Tools noch nicht kennengelernt.

In diesem Workshop zeigen wir, wie man mit **Astro** blitzschnell Webseiten für die Dokumentation
von Produkten oder Knowledgebases baut—Seiten, die nicht nur rattenscharf aussehen, sondern auch
in der Cloud richtig Gas geben.

Dann kommt der **Linting-Stack** ins Spiel—der digitale Putzteufel, der den Code auf Hochglanz
bringt, bevor ihn jemand zu sehen bekommt:

- **ESLint** schafft den Grobdreck im Code weg
- **Prettier** macht den Code hübsch
- **Vale** poliert die Prosa auf

Das fertige Ergebnis landet auf **GitHub Pages**—vollautomatisch via CI/CD. Für die lokale
Entwicklung steht optional ein **Docker-Container** bereit.

Und zum Abschluss: Weil kein Workshop heutzutage ohne KI auskommt, übersetzen wir die gesamte
Dokumentation vollautomatisch ins **Englische**—und als Spaß-Zugabe auch noch ins **Klingonische**
oder **Elbische**.

## Was entsteht am Ende?

Am Ende des Workshops läuft eine vollständige, produktionsreife Dokumentationsplattform:

| Komponente         | Details                                                                  |
| ------------------ | ------------------------------------------------------------------------ |
| **Astro-Website**  | Auf Basis von Starlight—dem offiziellen Astro-Dokumentations-Framework |
| **Linting-Stack**  | ESLint + Prettier + Vale, integriert in npm-Scripts und Git Hooks        |
| **GitHub Pages**   | Vollautomatisches Deployment via GitHub Actions bei jedem Push           |
| **Lokales Docker** | Nginx-Container für die lokale Vorschau (optional)                       |
| **KI-Übersetzung** | Node.js-Skript gegen den adesso AI Hub—Deutsch → Englisch (+ Spaß)    |

## Astro, Starlight und Astrogon—kurz erklärt

### Astro

**Astro** ist ein moderner Static Site Generator (SSG): Er baut zur Build-Zeit reines HTML—
kein JavaScript im Browser, kein Server, keine Laufzeitkosten. Das Ergebnis ist blitzschnell,
sicher und lässt sich überall hosten, wo statische Dateien liegen können—also auch auf
GitHub Pages.

### Starlight

**Starlight** ist das offizielle Dokumentations-Framework von Astro. Es baut auf Astro auf und
liefert out-of-the-box alles, was eine professionelle Doku braucht:

- Automatische Sidebar-Navigation aus der Ordnerstruktur
- Eingebaute Volltextsuche
- Mehrsprachigkeit (i18n)
- Dark Mode, Barrierefreiheit, Mobile-First
- Versionierung und "Edit on GitHub"-Links

Starlight ist die erste Wahl, wenn das Ziel eine reine Dokumentationsseite ist—schnell
aufgesetzt, sofort professionell.

### Warum Starlight?

Starlight ist die **erste Wahl für professionelle Produktdokumentationen**—und genau das bauen
wir in diesem Workshop. Es liefert alles out-of-the-box, was eine echte Doku braucht, ohne dass
man sich um Layout, Navigation oder Suche kümmern muss. Der Fokus liegt auf dem Inhalt und dem
Linting-Stack—nicht auf Theme-Basteln.

| Feature | Out-of-the-box in Starlight |
|---|---|
| Sidebar-Navigation | ✅ Automatisch aus Ordnerstruktur |
| Volltextsuche | ✅ Pagefind integriert |
| Dark Mode | ✅ |
| Mehrsprachigkeit (i18n) | ✅ |
| Barrierefreiheit | ✅ WCAG-konform |
| "Edit on GitHub"-Links | ✅ |
| Versionierung | ✅ |
| Linting-Vielfalt (`.astro`, `.ts`, `.md`, `.mdx`) | ✅—ideal für den Workshop |

## Für wen ist dieser Workshop?

Der Workshop richtet sich an Entwicklerinnen und Entwickler, die:

- eine Dokumentations- oder Projektwebsite professionell aufsetzen wollen
- ihren Code- und Prosa-Qualitätsprozess automatisieren möchten
- GitHub Pages als kostenloses Hosting nutzen wollen
- KI sinnvoll in ihren Entwicklungsworkflow integrieren möchten

**Voraussetzungen:** Ganz rudimentäre Kenntnisse in JavaScript/TypeScript, Mardkown Git und der Kommandozeile.
Astro-Vorkenntnisse sind nicht erforderlich—der Workshop beginnt bei null.
