Willkommen zum Astro/Starlight Workshop!

In diesem Workshop baust du Schritt für Schritt eine vollständige, produktionsreife
Dokumentationsplattform auf—von der ersten Zeile Code bis zur live geschalteten GitHub Page,
inklusive professionellem Linting-Stack und KI-gestützter Übersetzung.

## Was entsteht am Ende?

Am Ende des Workshops hast du eine fertig lauffähige Plattform am Start:

| Komponente         | Beschreibung                                                        |
| ------------------ | ------------------------------------------------------------------- |
| **Astro-Website**      | Auf Basis von Starlight—dem offiziellen Astro-Doku-Framework      |
| Linting-Stack      | ESLint (Code-Qualität), Prettier (Formatierung), Vale (Prosa)      |
| GitHub Pages       | Vollautomatisches Deployment via GitHub Actions                     |
| Lokales Docker     | Optionale Entwicklungsumgebung mit Nginx                            |
| KI-Übersetzung     | Automatische Übersetzung Deutsch→Englisch via adesso AI Hub         |
