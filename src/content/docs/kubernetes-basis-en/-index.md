Welcome to the 2-day Kubernetes Basics training!

Over the course of the two days, every participant builds a complete container environment with four
applications: Chromium Browser, Code-Server, MariaDB and phpMyAdmin -- all reachable behind Ingress
routing.

## Chapter overview

- [01 Introduction](/docs/kubernetes-basis-en/01-introduction) -- What this is about and what you end up with
- [02 Goals / Methods](/docs/kubernetes-basis-en/02-goals-methods) -- Learning objectives and didactic approach
- [03 Preparation](/docs/kubernetes-basis-en/03-preparation) -- Set up the environment, install the tools
- [10 Day 1](/docs/kubernetes-basis-en/10-day-1) -- Kubernetes concepts, deploy Chromium and Code-Server
- [20 Day 2](/docs/kubernetes-basis-en/20-day-2) -- Resources, probes, PVCs, exercise
- [90 Glossary](/docs/kubernetes-basis-en/90-glossary) -- All Kubernetes terms at a glance
