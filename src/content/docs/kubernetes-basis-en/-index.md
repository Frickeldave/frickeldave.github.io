Welcome to the 2-day Kubernetes Basics training!

Over the course of the two days, every participant builds a complete container environment with four
applications: Chromium Browser, Code-Server, MariaDB and phpMyAdmin -- all reachable behind Ingress
routing.

## Overview

- 01 Introduction -- What this is about and what you end up with
- 02 Goals / Methods -- Learning objectives and didactic approach
- 03 Preparation -- Set up the environment, install the tools
- 10 Day 1 -- Kubernetes concepts, deploy Chromium and Code-Server
- 20 Day 2 -- Resources, probes, PVCs, exercise
- 90 Glossary -- All Kubernetes terms at a glance
