# Content and Frontmatter Rules

Use for src/content and draft content changes.

## Key Rules

- Treat src/content.config.ts as the schema source of truth.
- Do not invent fields without schema updates.
- Publishable content should explicitly set visibility metadata.
- Keep filenames in kebab-case and metadata complete.

## Writing Standards

- German content uses consistent informal address (Du-form).
- Use inclusive language patterns and stable taxonomy terms.
- Reuse existing categories/tags before introducing new ones.

## Gate

Broad content process changes require requirement approval first (Tony).
