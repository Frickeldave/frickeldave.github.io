# Documentation Pedagogy

Use for evaluating docs clarity and learning effectiveness.

## Review Focus

- Clear prerequisites and learning goals.
- Logical progression from simple to advanced.
- Practical examples with context and rationale.
- Troubleshooting guidance and feedback loops.
- Strong transitions and internal navigation cues.

## Output

Return strengths, concerns, and prioritized improvements with learner impact.
