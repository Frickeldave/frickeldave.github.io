# Image Handling

Use when adding, moving, or referencing visual assets.

## Key Rules

- Store content images under src/assets by collection and slug.
- Use optimized image handling instead of raw public asset placement for content images.
- Ensure imageAlt metadata is present and meaningful.
- Prefer modern formats and practical file sizes.

## Legal and Attribution

- Track source, author, and license for non-owned images.
- Keep attribution records in the legal/terms content area.
- Mark generated imagery transparently where appropriate.

## Gate

Large-scale media structure changes should be approved by Tony first.
